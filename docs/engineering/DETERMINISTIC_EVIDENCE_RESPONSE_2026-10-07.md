## Mechanism change

Retire the ordinary factual response token-range selector. For ordinary factual
recall, deterministic code displays the bounded, admitted canonical records as
attributed quotations. It preserves conflicting statements rather than resolving
them by guesswork. When an application already knows the structured source and
field contract, an explicit typed source/field binding performs direct scalar
lookup, exact string copying and fixed or raw response rendering. Invalid bindings
fail without a model fallback. No additional model call or English phrase parser
is introduced.

A `RESPONSE_RENDER` artifact records the renderer version, committed policy,
canonical source records, bindings, separator, source references and output.
Receipts replay the renderer and reject any response-stage model invocation.
The native restart and factual continuity gates now require this receipt, and
all known requested values are checked. The supplied-policy relational test is
now a deterministic unit test requiring both the nickname and Docker Compose.
Live intent tests include the factual two-field continuity requests and print the
complete policy to expose accidental synthesis routing.

The current-only intent prompt also removes its conflicting invitation to use raw
output merely because a request names a code or identifier, and distinguishes a
request to look up a field from a declaration supplying it. This remains a semantic
classification task; prompt changes are not evidence that native classification
has been corrected.

## Interpretation and next gate

Source quotation guarantees faithful display of admitted records. It does not
establish that retrieval found every relevant record, that each record answers
the question, or that any assertion is external-world truth. Structured bindings
are supplied by an application with a known schema; arbitrary prose is not silently
converted into a fact database. Requests for explanations and other free-form
language still use synthesis. Exact raw output from unstructured prose may require
semantic extraction when no trusted binding exists.

Rerun the same native acceptance script at the published new commit, preserving
console output and artifacts. Factual response receipts must identify
`DETERMINISTIC_EVIDENCE_DISPLAY` or `DETERMINISTIC_SOURCE_VALUES` with no response
model. Human review must distinguish faithful evidence quotation from a resolved
semantic answer. This experiment does not imply native acceptance before that run.
