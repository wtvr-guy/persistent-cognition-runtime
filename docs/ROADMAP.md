# Engine roadmap

The repository contains the extracted current engine, including the v2 architecture and later retrieval, persistence, provenance, and model-execution improvements.

Maintain source provenance and reproducible installation. Evaluate future changes against frozen failures in retrieval, evidence authority, bounded context, resource admission, and recovery. Keep model-dependent acceptance separate from deterministic regression evidence.

Android, device synchronization, sensor collection, OS administration, desktop apps, and application mission policy are outside this repository's scope. See [EXTRACTION.md](EXTRACTION.md) for the pinned source boundary.
